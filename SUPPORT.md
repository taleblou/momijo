# Support

For usage and API questions, start with [the documentation](docs/README.md) and the closest example under `examples/`. For reproducible bugs, open a GitHub issue using the issue template. For change requests, choose the feature template.

Useful diagnostics include compiler and MAX versions, OS and device, exact command line, engine namespace, tensor shape/dtype/strides and a minimal source reproducer. Do not post credentials or private information. Vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public bug report.

This community project has no guaranteed response time, commercial SLA or declared support period.
